# New grad board

Full-time graduate roles for the **2027** class, refreshed on every `intern-watch` run —
FAANG+ and everyone else in separate tables, newest posting first, with location, visa
situation and salary. Same filters as the [internship board](README.md): postings older
than `MAX_AGE_DAYS` are dropped, as are the `EXCLUDE_REGIONS` groups.

> **Notifications are off until you set `NTFY_TOPIC_NEWGRAD`.** These lists are roughly
> three times the size of the internship ones, so the new grad track stays a silent board
> unless you opt in. Seed first (Actions → Run workflow → `seed`) or your first run will
> announce several hundred postings at once.

**Why this board matters more than the internship one if you need a visa:** sponsorship
is rare for a three-month internship and routine for a full-time graduate hire. The wall
is highest exactly where you are standing now.
